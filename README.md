## Abstract

Deep neural networks deployed in safety-critical domains (such as autonomous driving, medical diagnostics, and biometric security) achieve high test accuracy under identically distributed conditions, yet remain vulnerable to worst-case adversarial perturbations. By perturbing an input image with subtle, high-frequency gradient noise bounded by small $L_\infty$ norms, an adversary can manipulate network activations to induce high-confidence misclassifications while remaining imperceptible to human observers.

This project investigates the mechanics of first-order adversarial attacks and the efficacy of input-sanitization defenses. We implement a real-time experimental testbed evaluating:
1. **Adversarial Generation:** Single-step Fast Gradient Sign Method (FGSM) and iterative Projected Gradient Descent (PGD) across targeted and untargeted regimes.
2. **Perceptual and Metric Analysis:** Quantifying perturbations via $L_\infty$ bound, $L_2$ distance, and Peak Signal-to-Noise Ratio (PSNR).
3. **Empirical Defenses:** Evaluating the recovery rate of model predictions using spatial smoothing (Gaussian blur), median filtering, JPEG compression, and bit-depth quantization.

## 1. Problem Formulation & Theoretical Foundations

### 1.1 Standard vs. Adversarial Risk
Standard empirical risk minimization (ERM) optimizes average-case performance:
$$\min_{\theta} \mathbb{E}_{(x, y) \sim \mathcal{D}} [\mathcal{L}(f_\theta(x), y)]$$

In Trustworthy AI, models must satisfy **minimax adversarial robustness**, optimizing performance against the worst-case perturbation $\delta$ constrained within an allowable perturbation set $S$:
$$\min_{\theta} \mathbb{E}_{(x, y) \sim \mathcal{D}} \left[ \max_{\delta \in S} \mathcal{L}(f_\theta(x + \delta), y) \right]$$
where $S = \{ \delta \mid \|\delta\|_\infty \le \epsilon \}$ enforces an $L_\infty$ bound such that pixel alterations remain imperceptible.

### 1.2 Attack Formulations

#### Fast Gradient Sign Method (FGSM)
FGSM is a single-step first-order adversary that linearizes the loss function in the local neighborhood of the input $x$:
$$x_{adv} = \text{clip}_{[0, 1]} \left( x + \epsilon \cdot \text{sign}(\nabla_x \mathcal{L}(\theta, x, y_{true})) \right)$$
For **targeted attacks** aiming to force a specific malicious class $y_{target}$:
$$x_{adv} = \text{clip}_{[0, 1]} \left( x - \epsilon \cdot \text{sign}(\nabla_x \mathcal{L}(\theta, x, y_{target})) \right)$$

#### Projected Gradient Descent (PGD)
PGD is an iterative adversary that takes multiple gradient steps with step size $\alpha$, projecting back onto the $\epsilon$-ball around $x$ after each update:
$$x^{t+1} = \Pi_{x + S} \left( x^t + \alpha \cdot \text{sign}(\nabla_x \mathcal{L}(\theta, x^t, y)) \right)$$
where $\Pi_{x + S}$ denotes projection onto the feasible set $[0, 1]^d \cap B_\epsilon(x)$. PGD serves as the canonical benchmark for worst-case first-order robustness.

## 2. Empirical Defenses (Input Sanitization)

Adversarial perturbations generated by gradient sign methods rely heavily on fragile, high-frequency spatial patterns. We evaluate four preprocessing defenses applied prior to model inference:

1. **Spatial Gaussian Smoothing:** Convolves the image with a 2D Gaussian kernel ($k \times k$, standard deviation $\sigma$) to attenuate high-frequency gradient noise.
2. **Median Filtering:** Applies a non-linear sliding rank filter to eliminate isolated adversarial gradient spikes while preserving edges.
3. **JPEG Compression Simulation:** Transforms the input into frequency space via Discrete Cosine Transform (DCT) and discards high-frequency components through lossy quantization.
4. **Bit-Depth Quantization:** Maps continuous pixel values to discrete levels ($2^b$ bins, $b \in [2, 6]$), removing small continuous perturbations ($\|\delta\| < 2^{-b}$).

## 3. System Architecture

The project is structured into modular components separating attack algorithms, defensive filters, model wrappers, and the visualization engine:

```
ProjectTai/
├── app.py               # Interactive dashboard & visualization pipeline
├── attacks.py           # PyTorch FGSM & PGD implementations (targeted/untargeted)
├── defenses.py          # Input preprocessing transformations (Gaussian, Median, JPEG, Quantization)

├── download_samples.py  # ImageNet benchmark sample acquisition
├── test_pipeline.py     # Automated unit test suite verifying attacks and defenses
├── run.bat              # Local startup script
└── sample_images/       # Standard benchmark test samples (Stop Sign, Panda, Dog, Cat, Lemon)
```

### Input Normalization Wrapper
ImageNet architectures expect inputs normalized by mean $\mu = [0.485, 0.456, 0.406]$ and std $\sigma = [0.229, 0.224, 0.225]$. To compute attacks directly in valid pixel space $[0, 1]$, models are wrapped in a custom `NormalizedModel` layer:
$$\tilde{x} = \frac{x - \mu}{\sigma}, \quad \hat{y} = f_{base}(\tilde{x})$$
This guarantees that clipping $\text{clip}_{[0, 1]}$ and metric calculations ($L_\infty, L_2, \text{PSNR}$) accurately reflect real-world pixel values.

## 4. Key Experimental Observations

1. **Linearity in High Dimensions:** Deep convolutional networks exhibit severe vulnerability even at small perturbation budgets ($\epsilon = 0.04$). A $4\%$ change per color channel is sufficient to reduce classification accuracy to near $0\%$ on tested samples while remaining undetectable to human inspection.
2. **Targeted Manipulation in Safety Scenarios:** Under iterative PGD, a physical road sign (*Stop Sign*) can be reliably converted into completely unrelated categories (*Speed Limit*, *Toaster*) with $>90\%$ model confidence.
3. **Efficacy and Limitations of Input Preprocessing:**
   * Gaussian blur ($5 \times 5, \sigma=1.5$) and JPEG compression (Quality $= 40$) successfully restore the ground-truth prediction for moderate single-step attacks ($\epsilon \le 0.06$).
   * However, higher-budget iterative attacks ($\epsilon \ge 0.12$) saturate larger feature channels, where simple preprocessing is insufficient and robust training (e.g., adversarial training) becomes necessary.

## 5. Setup and Execution

### Prerequisites
- Python 3.10+ (tested on Python 3.13)
- PyTorch 2.0+ (CPU or CUDA)
- Streamlit, Torchvision, Pillow, NumPy, Matplotlib

### Installation
1. Clone or extract the repository into your working directory:
   ```powershell
   cd ProjectTai
   ```

2. Create a virtual environment and activate it:
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\activate
   ```

3. Install required packages:
   ```powershell
   pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
   pip install streamlit pillow matplotlib
   ```

4. Verify setup and run the pipeline test:
   ```powershell
   python test_pipeline.py
   ```

### Running the Application
Launch the interactive dashboard:
```powershell
streamlit run app.py
```
*(On Windows, you can alternatively execute `run.bat` directly).*

Access the interface via your browser at `http://localhost:8501`.
